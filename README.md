# Temperature Sensor

Dispatch Pro **Temperature Sensor** — a single-file prototype (`index.html`, no build step).

- **Asset log:** fleet list with last tire temperature, status filters, search, Truck/Trailer toggle, sortable columns and an Overall Fleet Status donut.
- **Asset page:** 3D truck/trailer with per-axle heat bars (Three.js), hover cards, hottest-tire gauge, axle table, 24 h / 7 d history chart, re-scan, CSV export.
- **Limits & alerts:** per-axle max temperature, alert delay, near-limit margin and notification recipients; saving re-derives fleet status.
- Light and dark themes, shadcn/ui-at-80% design system. Settings persist in `localStorage`.

Open `index.html` in a browser (it loads Lucide, Three.js and Inter from CDNs).
